# ProContract project page

Static site for the paper *ProContract: Decoupling Responsibility and Progress from an Evolvable Harness*.

- `index.html`, `static/css/style.css`, `static/js/main.js`: the page (no build step, no framework).
- `static/images/`: figures exported from the paper; `static/files/procontract.pdf`: the preprint.

Preview: open `index.html` in a browser.

Publish: repository **Settings → Pages → Deploy from a branch → `project-page` / root**.
The page shows the authors' names, so publish it only when the paper may be de-anonymized.
When the preprint and the code are public, replace the two "soon" items in the top navigation of `index.html`
with the arXiv link and remove the badge from the Code link.
